# Round 1: equality, trace and measurement contracts

A server compares a received 32-byte authentication tag with its expected tag.
Length is public. Equality is deliberately released; matched-prefix length is
not. First- and last-mismatch inputs both return false, making their differing
paths a useful demonstration of excess disclosure.

Early exit costs approximately h+c(j+1), where h is fixed overhead, c per-byte
cost and j the first mismatch's zero-based position. At32 bytes, first versus
last gives h+c versus h+32c. A full scan costs approximately
h+v*ceil(n/w)+r, where n is public length,w bytes per loop step,v step cost,
and r remainder/reduction cost. With n32,w16, this is h+2v+r. These are work
models; compiler lowering and branch prediction affect measured cost.

Public loop bounds are compatible with constant-time discipline. Secret-indexed
memory, secret-dependent branches and target-specific operand timing require
separate review. Source shape is not a compiler promise. std::hint::black_box
is used only to preserve benchmark work; it supplies no cryptographic guarantee.

The Choice-to-bool conversion in reviewed releases the final allowed answer.
Keep intermediate choices inside appropriate operations when they remain secret.
Unequal-length short circuit is acceptable only under this public-length contract.

Prefer the authentication scheme's verification API or a reviewed primitive for
secret comparisons. XOR throughput success does not authorize a replacement.
Assembly inspection and leakage tests apply to the exact build and threat model.
This round does not test speculative/physical channels or complete a dudect run.
