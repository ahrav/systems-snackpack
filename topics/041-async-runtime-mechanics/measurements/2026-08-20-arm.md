## Observations

All eight fresh processes produced identical output. Each reported a 4,099-byte
future when the 4,096-byte array crossed suspension and a 16-byte future when
only the checksum crossed suspension. Both checksums were 522,240. The unsafe
losing receive left the right queue empty; the safe loser left one parcel.

Rust Mid-level Intermediate Representation (MIR) stored the 4,096-byte array and
`YieldOnce` together in the suspended large variant. The small suspended variant
stored the `u64` checksum and `YieldOnce`; its array remained a nonsuspended
local. Native linked symbol sizes were 56 bytes for `YieldOnce::poll`, 180 bytes
for `SafeTake::poll`, and 208 bytes for `UnsafeTake::poll`.

These byte counts are exact observations for this compiler, flags, source, and
host. They are not a stable Rust application binary interface (ABI) or a claim
about other Arm systems.
