## Observations

All eight fresh processes produced identical output. Each reported a 4,099-byte
future when the 4,096-byte array crossed suspension and a 16-byte future when
only the checksum crossed suspension. Both checksums were 522,240. The unsafe
losing receive left the right queue empty; the safe loser left one parcel.

MIR showed the same suspended-state distinction as the Arm build. Native linked
symbol sizes were 28 bytes for `YieldOnce::poll`, 151 bytes for
`SafeTake::poll`, and 195 bytes for `UnsafeTake::poll`.

These byte counts are exact observations for this compiler, flags, source, and
host. They are not a stable Rust ABI or a claim about other x86-64 systems.
