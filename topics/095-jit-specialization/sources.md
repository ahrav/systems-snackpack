# Primary sources

Accessed 2026-11-01.

- [V8 Maglev](https://v8.dev/blog/maglev): profile specialization, shape guards, dependency invalidation, and frame-state reconstruction.
- [V8 fast properties](https://v8.dev/blog/fast-properties): object shapes and property storage.
- [V8 speculative Wasm optimization](https://v8.dev/blog/wasm-speculative-optimizations): guarded indirect-call inlining, code-size budgets, and deoptimization.
- [Correctness of Speculative Optimizations with Dynamic Deoptimization](https://arxiv.org/abs/1711.03050): assumptions, state translation, and semantic equivalence.

Engine descriptions apply to the documented pipelines and revisions. Measured
Node/V8 versions and observed traces are recorded separately in results.md.
