## Generated code and interpretation

The scalar control used scalar byte comparisons and was unrolled four bytes at
a time. The AVX2 implementation used `vpbroadcastb`, `vpcmpeqb`,
`vpmovmskb`, and `vzeroupper`; this baseline build emitted scalar mask-counting
instructions rather than `popcnt`. The retained `resolve_best` body read
Rust's feature-detection cache, branched on the AVX2 bit, and called the
detection initializer when the cache was empty. `count_eq_dispatch_once`
called that resolver and tail-jumped through the returned function address.
These are observations of the linked binary, not source-level expectations.

The run did not collect performance-monitoring-unit events, frequency
residency, CPU isolation, or concurrent-load measurements. It therefore does
not identify the hardware cause of a timing difference. The resolver branches
and the paired timing differences are observed separately; claiming that one
specific branch or indirect call caused the difference would be inference.
