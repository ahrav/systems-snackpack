# Round 01: make cache policy explicit

The first visit separates four contracts that applications can collapse:

1. page-cache residency;
2. read-ahead policy;
3. dirty-data writeback;
4. direct-I/O alignment and concurrency.

The Rust crate checks the decision arithmetic. The native experiment uses a
fixed, balanced process schedule on the required Arm and x86-64 hosts. It
records residency, I/O accounting, timing, compiler output, host identity, and
source identity. Timing intervals use complete process blocks as the independent
units.

The experiment does not treat page-cache eviction as a cold-device guarantee.
It does not generalize either host to an instruction-set or vendor family.
