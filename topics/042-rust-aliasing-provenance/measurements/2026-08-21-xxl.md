## Question and boundary

This run asks whether one exact committed Rust program preserves its defined
Strict Provenance, reference, and raw-pointer results through the required
`xxl` alias, and which alias attributes and memory operations the selected
compiler emits. It reports no elapsed time. Eight processes replicate
deterministic correctness, not performance.
