# Round 1: Error contracts survive the lifecycle

Date: 2026-09-28.

The focused question is whether a summary preserves its meaning through merges,
replay, and finite arithmetic. Ten unit tests and one doctest pass on both
required Linux hosts. All local workspace gates pass.

Sixteen fixed hash-mixer seeds show Bloom false positives rising from a median
1.017% with 10,000 inserted keys to 15.719% with 20,000 keys in the same 95,851-bit
array. No inserted key is missed. The range across seeds is descriptive, not a
confidence interval or proof of a hash independence theorem.

Count-Min merging matches serial ingestion, but merging one partition twice
changes total weight from 3,997 to 5,997. Unsafe bit deletion, arbitrary negative
frequencies, and saturating counters have separate counterexamples.

See [measurements](../measurements/README.md) for exact-source identity, host
metadata, code-generation inspection and retained receipts. The [source ledger](../references.md)
separates textbook assumptions from experiment claims. No latency or throughput
comparison is made, and no production filter or HLL implementation is evaluated.
