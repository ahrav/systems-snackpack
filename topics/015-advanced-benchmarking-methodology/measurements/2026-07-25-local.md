The timer covered each 32 MiB checksum call. Process startup, allocation,
initialization, and the 256 MiB eviction traversal remained outside the timed
regions.

The raw CSVs were written to ephemeral `/tmp` paths and are not retained.
Treat this as an exploratory harness check, not durable performance evidence.
The retained Linux records below provide the reproducible evidence set.

Twenty-four fresh processes formed twelve `AB`/`BA` blocks. Median ratios and
type-7 interquartile ranges were:

| Metric | Median | IQR |
|---|---:|---:|
| First position / second position | 2.503551 | 0.475235 |
| Fixed `AB`, label A / label B | 2.584659 | 0.418526 |
| Fixed `BA`, label A / label B | 0.402976 | 0.084600 |
| Order-cancelled label A / label B | 1.043476 | 0.077683 |

The identical labels reversed apparent winners under fixed order. The balanced
geometric contrast moved the apparent label ratio toward `1`; it did not make
the estimate equal to `1`. This construction cancels a stable reciprocal
multiplicative position effect, not arbitrary order interactions.
