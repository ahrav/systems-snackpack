# Round 1: Causal order under a backward wall reading

Date: 2026-08-08

## Question

When a causal successor reads a wall clock 100 ms below its predecessor, which
timestamp models preserve the known order, and which model can also identify an
independent pair?

## Fixed event graph

The probe injects values; it never reads or changes host wall time.

```text
A paid: wall=1000
    |
    +-- message carrying logical state --> B packed: wall=900

independent controls:
A cancelled: [1,0]                  B shipped: [0,1]
```

The `paid` send happens before the `packed` receive. The two independent vector
events have no message edge.

## Deterministic acceptance contract

Each fresh process must establish all six results:

1. Wall-clock LWW selects the causal predecessor.
2. Lamport assigns `1` then `2` to the causal chain.
3. Vector `[1,0]` precedes `[1,1]`.
4. Vectors `[1,0]` and `[0,1]` are concurrent.
5. HLC assigns `(1000,0)` then `(1000,1)` despite B's `900 ms` wall input.
6. Intervals `[990,1010]` and `[1000,1020]` overlap, so physical order is
   unknown.

Checked arithmetic must reject Lamport or HLC logical-counter overflow. Interval
construction must reject an upper endpoint below its lower endpoint.

## Execution unit and replication

One fresh `ordering-probe --self-check` process is the execution unit. The fixed
schedule contains eight process slots. The runner records every exit status,
standard output, standard error, and SHA-256 digest. It does not replace a failed
slot.

Replication checks process startup and deterministic receipt production. It is
not statistical sampling and creates no performance interval.

## Why no benchmark is justified

The treatments differ in information and correctness, not a meaningful local
throughput estimand. A microbenchmark would time a handful of comparisons and
maximum operations. It would omit the costs that distinguish deployed designs:
message metadata, serialization, persistence, network delay, clock-health
validation, uncertainty wait, conflict retention, and quorum agreement.

Generated-code inspection verifies that the intended state transitions remain
in the final binary. It does not rank techniques by speed.

## Controls

- The wall selector's positive control uses a later B timestamp and must select
  B.
- The vector equality and reverse-dominance cases check all four relation
  outcomes.
- The independent vector pair prevents scalar-sum comparison from passing.
- Overflow tests ensure finite counters fail closed.
- Overlapping and disjoint intervals separate “unknown” from “definitely
  before.”
- Native and generic builds must produce identical correctness receipts.

## Measured, derived, and inferred

- **Observed:** process outputs, exits, hashes, host identity, toolchain, target
  features, binary symbols, and generated instructions.
- **Derived and validated:** causal relation outcomes, receipt digests, source
  identity, and exact process count.
- **Inferred only:** how a networked database, time service, replication group,
  or consensus implementation would behave.
