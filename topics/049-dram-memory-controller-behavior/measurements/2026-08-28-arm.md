# Required AArch64 host: 2026-08-28

This result compares one 512 MiB dependent pointer chain with idle workers and
with eight established read-only stream workers. It measures an exact-host
loaded-treatment effect. It does not measure DRAM-only service time, row state,
controller queues, channel traffic, or a scheduling policy.

## Accepted fixed-horizon campaign

The primary comparison used six `ABBA` and six `BAAB` four-process blocks: 24
fresh idle and 24 fresh loaded processes. Four loaded/loaded A/A blocks added
16 fresh processes. The accepted campaign therefore contains 64 fresh process
identifiers and no replacements.

| Observation | Idle minimum / median / maximum | Loaded minimum / median / maximum |
|---|---:|---:|
| Large chain, ns/load | 139.544 / 140.436 / 141.507 | 197.729 / 198.965 / 201.273 |
| Small 8 KiB control, ns/load | 1.928 / 1.935 / 2.098 | 1.929 / 1.935 / 2.156 |
| Full run epoch, ms | 4,788.464 / 4,816.963 / 4,858.892 | 6,740.360 / 6,785.202 / 6,864.462 |

| Contrast | Ratio | 95% t interval | Block range | Log-ratio SD |
|---|---:|---:|---:|---:|
| Loaded/idle large chain, 12 blocks | 1.417803 | 1.413943-1.421674 | 1.407097-1.427169 | 0.004291 |
| Loaded/idle small control, 12 blocks | 1.003146 | 0.988241-1.018276 | 0.962403-1.056205 | 0.023561 |
| Loaded-path B/A A/A large chain, 4 blocks | 0.998369 | 0.994805-1.001947 | 0.995711-1.000819 | 0.002248 |

Each interval covers between-block variation for this exact host, binary,
input, placement, and run window. It assumes independent, approximately normal
block log contrasts. The 41.78% point increase is an end-to-end treatment
effect. The stable earlier small control weakens explanations that affect both
timing windows uniformly, but it does not identify a DRAM mechanism.

Loaded workers consumed a median useful-source lower bound of `133.912643
GiB/s` and median inclusive upper bound of `133.912931 GiB/s`. Across the 24
loaded primary processes, the lower minimum was `133.078703 GiB/s` and the
inclusive upper maximum was `134.272093 GiB/s`. The possible uncounted tail is
at most 2 MiB per process. These are application source-byte rates over the
full worker epoch, not hardware traffic.

## Fault and scheduler boundary

Across all 64 accepted processes, process-wide and probe-thread minor faults,
major faults, voluntary context switches, and process-lifetime major faults
were zero in the large-walk counter window. Involuntary context switches were:

- primary idle: process and probe thread 8-58, median 13;
- primary loaded: process 80-217, median 97; probe thread 10-139, median 16.5;
- A/A loaded: process 79-231, median 97; probe thread 12-153, median 15.5.

Process-wide counters include workers; probe-thread counters do not. A process
switch count is not evidence that the probe was preempted.

## Rejected first campaign

The first fixed-horizon Arm campaign was rejected as a whole. Its first 63
periods passed, but attempt 64 recorded 70 process minor faults, 34 probe-thread
minor faults, zero major faults, 10,165 process involuntary context switches,
and 6,009 probe-thread involuntary context switches. None of that campaign's
estimates are used and the failed period was not replaced.

A controller-observed full-size diagnostic then passed the fault canaries. It
was not retained and contributes no estimate. The complete retry started from
a fresh fixed schedule and produced the accepted receipt above. The rejected
campaign is preserved beside it.

## Linked code and receipt

The linked walker scaled the index with `lsl #6` and loaded the next dependent
index with `ldr`. The stream used Scalable Vector Extension (SVE) `ld1d`,
`incd`, and predicated vector addition. The timed wrapper called the linked
walker between raw monotonic clock reads. This proves instruction and
dependency shapes, not runtime row state or controller activity.

[`raw/2026-08-28-8ad9502/arm-retry2-results.tar.gz`](raw/2026-08-28-8ad9502/arm-retry2-results.tar.gz)
is the accepted sealed receipt. Its outer SHA-256 is
