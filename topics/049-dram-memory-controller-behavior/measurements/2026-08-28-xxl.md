# Runtime-resolved `xxl` host: 2026-08-28

This result compares one 512 MiB dependent pointer chain with idle workers and
with eight established read-only stream workers. It measures an exact-host
loaded-treatment effect, not a DRAM mechanism.

Each interval covers between-block variation for this exact host, binary,
input, placement, and run window. The 8.38% point increase is an end-to-end
treatment effect. The stable small control and centered A/A path narrow some
alternatives but do not identify where in the shared memory hierarchy the
workers competed.

Loaded workers consumed a median useful-source lower bound of `77.759694 GiB/s`
and median inclusive upper bound of `77.760023 GiB/s`. Across the 24 loaded
primary processes, the lower minimum was `77.285024 GiB/s` and the inclusive
upper maximum was `78.155912 GiB/s`. These are source-byte bounds over the full
worker epoch, not cache, fabric, controller, or DRAM traffic.

## Fault and scheduler boundary

All process-wide and probe-thread minor- and major-fault fields were zero for
all 64 processes despite automatic NUMA balancing being enabled. The accepted
campaign therefore excludes timed page faults as a contributor. Earlier faults
were consistent with automatic-NUMA hinting, but their mechanism was not
identified contemporaneously. The receipt does not query every page's physical
NUMA location.

Involuntary context switches were:

- primary idle: process and probe thread 21-38, median 28.5;
- primary loaded: process 82-137, median 93; probe thread 26-38, median 31;
- A/A loaded: process 83-107, median 95; probe thread 26-38, median 30.5.

All voluntary-switch and process-lifetime major-fault fields were zero.

## Linked code and receipt

The linked walker used `shl $0x6`, a payload load, and a dependent `mov` for
the next index. The stream used 256-bit `vpaddq`, advanced by 32 bytes, then
reduced horizontally. The timed wrapper called `clock_gettime` with the source's
`CLOCK_MONOTONIC_RAW` before and after the walker. Static assembly proves these
shapes, not cache residency or DRAM activity.
