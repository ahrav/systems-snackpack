# Round 1: write allocation and forwarding geometry

## Decision rule

Use the block-level `B/A` time ratio and its 95% Student-t interval. An interval
entirely below one supports lower time for `B`; an interval entirely above one
supports higher time; an interval containing one is inconclusive for this run.
If the corresponding A/A interval excludes one, treat the primary comparison as
path-confounded and make no direction claim. Otherwise report the control width
with the primary estimate; inclusion of one does not prove absence of bias.

Retain the temporal write path unless the non-temporal interval is entirely
below one, publication and full-pattern checks pass, the timed period incurs no
faults, and final-image inspection confirms the required instruction sequence.
That decision applies only to one-pass, full-line overwrites with the measured
publication boundary.

Call a partial-overlap STLF penalty only when the partial/exact interval is
entirely above one, its A/A diagnostic remains non-directional, the oracle
matches, and disassembly confirms the exact and `+4` load addresses. An interval
containing one leaves the geometry effect unresolved.

## Cost model

The x86-64 temporal arm can allocate destination lines through the cache
hierarchy. The streaming arm can avoid that allocation for complete aligned
lines, but it consumes write-combining resources and includes `SFENCE` before
publication. The model therefore predicts a benefit only when avoided
allocation and reduced cache displacement exceed streaming-buffer and fence
costs.

Arm `STNP` supplies an allocation hint rather than a cache-bypass guarantee.
Both Arm arms use normal-memory pair stores and the same release publication.
Any timing difference remains specific to the measured implementation and host.

An exact load can forward the preceding eight-byte store when the
microarchitecture recognizes the size and address match. The `+4` load needs
four bytes from that store and four bytes from the unchanged fixture. A failed
or delayed forwarding path extends every iteration because the loaded value is
the next stored value. The 500,000,000-iteration recurrence amplifies latency;
it does not model independent memory-level parallelism.

## Evidence limits

- Source intrinsics and assembly establish intent; complete linked function
  bodies establish the instruction sequence executed by the benchmark.
- Instruction shape alone does not establish write allocation, forwarding,
  replay, or cache traffic. The first-round runner collects no counters.
- Same-thread verification checks publication value and bytes after timing. It
  does not measure consumer wake-up or cross-thread visibility latency.
- The write result cannot select a policy for partial lines, reused data, small
  buffers, or a different durability boundary.
- The STLF result cannot generalize beyond the measured store size, load size,
  alignment, offset, dependency chain, CPU, and run window.
