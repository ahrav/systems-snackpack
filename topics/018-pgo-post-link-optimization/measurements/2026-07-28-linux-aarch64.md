## Generated code and interpretation

The baseline `dispatch` contains an indirect `blr x8`. Both PGO candidates
contain a function-pointer comparison, a direct `bl` to the target observed
during training, and a fallback `blr x8`. Checksums matched across all four
binaries for `alpha`, `beta`, and `noop`.

The timing and instruction text are observations. A plausible explanation is
that this guarded promotion adds more cost than it removes in this fixture, but
the run did not measure branch prediction, indirect-predictor behavior, or
front-end events. It therefore does not attribute the slowdown to that
transformation or to the CPU.

`perf` was available on `PATH`. `llvm-bolt`, `perf2bolt`, and `merge-fdata`
were unavailable on `PATH`, so this run makes no measured BOLT claim.
