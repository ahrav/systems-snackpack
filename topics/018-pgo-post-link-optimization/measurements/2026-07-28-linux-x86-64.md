## Generated code and interpretation

The baseline `dispatch` contains an indirect `call *%rax`. Both PGO candidates
compare the function pointer, call the target observed during training
directly, and retain an indirect fallback. Checksums matched across all four
binaries for `alpha`, `beta`, and `noop`.

The timing and instruction text are observations. A plausible explanation is
that the guarded promotion changes branch and indirect-call behavior in a way
that is unfavorable here, but no branch, indirect-predictor, or front-end
counter was collected. The run therefore does not attribute either slowdown or
the profile-choice effect to that transformation or to the CPU.

`perf` was available on `PATH`. `llvm-bolt`, `perf2bolt`, and `merge-fdata`
were unavailable on `PATH`, so this run makes no measured BOLT claim.

orders, intervals and dispersion, raw and merged profiles, profile and binary
hashes, final disassembly, correctness checks, source manifests, host and
