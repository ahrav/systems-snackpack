# `xxl` exact-source NUMA measurement: 2026-08-04

## What this run tests

This run asks whether a fixed worker takes longer to chase pages first placed on
the other NUMA node than pages placed beside that worker. It tests both node
directions and runs a mechanically identical A/A control. It does not measure
page-migration cost, sustained bandwidth, long-lived automatic balancing, or
another processor.

## Fixed process design

Each fresh process mapped 512 MiB as 131,072 base pages and completed four full
single-cycle pointer-chase passes, or 524,288 dependent loads. Direction 0 fixed
the worker on CPU 0 and compared node-0 pages with node-1 pages. Direction 1
fixed the worker on CPU 48 and compared node-1 pages with node-0 pages.

Each direction used eight complete four-process A/B blocks, balanced between
`ABBA` and `BAAB`, plus four A/A blocks through the same schedule paths. The run
contained 96 fresh processes. The complete block, not an inner load or process,
is the analysis unit.

The pooled 16-block ratio was 1.5575 [1.5434, 1.5718]. Direction-specific
ratios are primary because the two directions need not be symmetric.

The A/A diagnostics were 1.0015 [0.9764, 1.0272] on direction 0 and 0.9956
[0.9736, 1.0181] on direction 1. Both include 1.0.

Each interval is a two-sided Student-t interval over the eight complete block
log contrasts in that direction. It covers block-to-block variation during this
39-second run window under the model behind that interval. It does not cover
other hosts, builds, access patterns, mapping sizes, process lifetimes, or
automatic-balancing convergence.

## Measured, observed, and inferred

- **Measured:** per-process chase time, block contrasts, ratios, intervals, and
  fault counts.
- **Observed:** CPU/node topology, per-page placement before and after, policy
  state, final binary instructions, and checksums.
- **Inferred:** the higher time is consistent with crossing the host's NUMA
  interconnect. No memory-controller or interconnect counter was collected, so
  this run does not assign the complete difference to one hardware component.

These numbers apply only to this host, binary, mapping, access chain, placement,
and run window. They are not an x86-64 or Intel-family constant.
