# Measurement records

No validated host result is checked in yet. Each published result must identify
one exact source archive and one authorized Linux host. Its raw receipt retains
host metadata, correctness and build logs, process records, statistical
summaries, generated code, validation, and SHA-256 digests. A host note may
summarize that receipt; a cross-host note may compare observations without
generalizing either machine to an architecture or vendor family.

The experiment measures elapsed time. Disassembly records generated code.
Processor manuals support mechanism hypotheses. None of these receipts proves
that a mitigation closes a security boundary.
