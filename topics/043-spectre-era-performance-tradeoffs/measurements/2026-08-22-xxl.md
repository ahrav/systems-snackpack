## Observed code and interpretation

The plain path used `cmp`, conditional `jae`, then a memory-source `mov`. The
masked path used `cmp`, `sbb`, `and`, and a memory operand; Rust also retained a
post-mask bounds branch. The barrier path placed `lfence` after `jae` and before
the load.

The committed generator and seed derive 9,999,927 invalid indices from
20,000,000 timed lookups, or 49.999635%. That is a source-derived count, not a
hardware counter. The mask result therefore reflects this input's branch
predictability as well as its data dependency. The barrier executes only for
valid indices. No branch-miss counter or transient-disclosure test was run.

The kernel reported Enhanced or Automatic Indirect Branch Restricted
Speculation (IBRS), conditional Indirect Branch Prediction Barriers (IBPB), a
post-barrier return-stack sequence, and the `BHI_DIS_S` hardware control for
Branch History Injection. These are kernel policy observations, not proof
about this lookup's security.
