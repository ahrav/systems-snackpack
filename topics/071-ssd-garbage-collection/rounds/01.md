# Round 01: account for copied pages and free inventory

Taught 2026-10-08 before repository mutation. The complete lesson and inspected diagram are retained outside Git. This artifact holds the model, tests, commands and compact evidence.

Compare selection overhead separately from programmed-page work. For a 12-page victim with eight live pages, copying eight and accepting four new host pages gives WAF 3. A window that copies eight but accepts only one new page gives WAF 9 and adds three writable pages. Both satisfy the same inventory identity.

Correctness precedes ranking. The six paired process blocks use all policy-order permutations, matched trace seeds and CPU affinity. See EXPERIMENT.md for timing boundaries and final selection rules. Initial scratch runs are descriptive and never pooled with committed-source runs.

Production choice additionally needs the exact SSD/firmware, page and reclaim geometry, production fill/history, supported media-write counters, stable observation windows, wear distribution and latency objectives. Host write counters or a fresh-space burst alone cannot establish device WAF.
