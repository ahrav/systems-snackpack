# Round 1: Opposing periodic traps

Date: 2026-08-13

## Question

Can one deterministic byte-search probe show that preparation reuse and input
structure change the relative cost of left-to-right comparison,
Knuth-Morris-Pratt (KMP), and Boyer-Moore-Horspool without declaring a universal
winner?

## Acceptance contract

Before timing, every host run must establish:

1. All three matchers agree with an independent nested-loop oracle on fixed
   edge cases.
2. They agree on all 32,193 binary-alphabet pairs with haystack lengths zero
   through eight and needle lengths zero through five.
3. They agree on at least 10,000 deterministic full-byte input pairs.
4. Every benchmark case has one expected first-match result and stable input
   checksum across methods.
5. Empty needles, longer needles, overlaps, zero bytes, and `0xff` bytes follow
   the declared byte-search contract.

Any disagreement invalidates the run. Its timing remains retained as a failed
attempt but cannot be promoted as evidence.

## Execution and analysis units

One fresh process selects one method and emits all case and timing-mode rows.
The runner applies two pairwise treatment families: left-to-right versus KMP,
and left-to-right versus Horspool. Each family contains 12 complete four-period
`ABBA` or `BAAB` blocks in a fixed seed-shuffled order. Family order is balanced
and the stopping rule is fixed before execution. The two families plus four
same-method blocks produce 112 timed processes and 1,120 result rows per host.

The analysis unit is one complete block contrast. A process is the treatment
application unit. Repeated searches inside a timed interval are subsamples, not
independent observations. A new process identifier does not prove statistical
independence because processes share the host, scheduler, caches, thermal
conditions, and neighboring work.

For an `ABBA` block, the candidate-versus-baseline log contrast is:

```text
d = ((log(B2) + log(B3)) - (log(A1) + log(A4))) / 2
```

For `BAAB`, `B` occupies periods one and four. The point estimate is
`exp(mean(d))` across 12 blocks. The sample standard deviation of `d` describes
block-to-block variation during that run window. This ordering cancels an
additive linear position trend under the declared model; it does not remove
nonlinear drift or shared-host interference.

## Timing boundaries

- `reuse` constructs KMP and Horspool plans before the interval and warms one
  query before timing.
- Every `one_shot` timed iteration constructs a plan, runs one query, and
  destroys that plan.
- Corpus construction, oracle validation, calibration, output, and process
  startup stay outside both intervals.
- A retained host-specific calibration chooses and freezes repetition counts.
- Each result contributes to an observable checksum.
- Logical bytes divided by elapsed time is logical input throughput, not memory
  bandwidth.

## Controls

- Five cases keep favorable, ordinary, small, and opposing periodic behavior
  separate.
- Each family compares the same case, mode, repetition map, affinity, binary,
  and environment in all four periods.
- Four `ABBA` or `BAAB` blocks map both labels to the same left-to-right method
  to check scheduling and analysis. Their spread is not called a noise floor.
- The first processor allowed by the process affinity mask is pinned; processor
  zero is not assumed to be available.
- Generic and native builds must both pass correctness. Timing uses one exact
  native binary per host.
- Exported non-inlined hooks retain linked code for disassembly, the final
  executable's machine-instruction listing.
- Every attempt is retained and output directories are never reused.

## Evidence boundary

- **Measured:** elapsed monotonic time, process wall time, host and toolchain
  metadata, first-match results, input and output checksums, process order,
  binary hashes, and linked instructions.
- **Derived and validated:** nanoseconds per search, logical throughput,
  complete-block log contrasts, geometric-mean ratios, and within-window sample
  standard deviations.
- **Source-backed:** algorithm guarantees and current library selection rules
  cited in `references.md`.
- **Inferred:** effects from branch prediction, cache behavior, allocation,
  instruction throughput, or candidate selectivity unless a separate counter
  or trace directly measures them.
- **Not tested:** Unicode equivalence, multi-pattern matching, a production
  corpus, host libc search, third-party matchers, or any architecture family.

## Promotion gate

Commit and push the source candidate before retained measurement. Run an archive
of that exact commit on the literal required Arm host and on the runtime-resolved
`xxl` Secure Shell (SSH) alias after confirming it is x86-64. Promote evidence
only when the hosts use one shared source archive, all correctness and benchmark
receipts validate, required linked-code inspection succeeds, and every workspace
gate passes. Documentation-only evidence commits may follow the measured source
commit, but they must not change the measured code.
