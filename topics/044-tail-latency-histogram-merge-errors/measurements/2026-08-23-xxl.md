## Generated code

The optimized standalone assembly retained `topic44_checked_merge_four`.
This exact rustc build used four `movq` loads, four memory-source `addq`
instructions, and `jb` overflow branches. Only after every addition succeeded
did four `movq` instructions write the results. The observed store placement
matches the function's transactional source contract.

This observation applies only to the recorded compiler, source, flags, and host.
It does not prove that all x86-64 compilers use this sequence or that it is
faster than another lowering.
