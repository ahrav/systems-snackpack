## Generated code

The optimized standalone assembly retained `topic44_checked_merge_four`.
This exact rustc build used four pairs of `ldr` loads, four flag-setting `adds`
instructions, and `b.hs` overflow branches. Only after every addition succeeded
did two `stp` instructions write the four results. The observed store placement
matches the function's transactional source contract.

This observation applies only to the recorded compiler, source, flags, and host.
It does not prove that all AArch64 compilers use this sequence or that it is
faster than another lowering.
