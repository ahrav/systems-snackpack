# Round 01: ordered publication and copy-on-write boundaries

This visit models metadata journaling, tree copy-on-write, synchronous logs,
and the application protocol for replacing one file. The native experiment
checks the application protocol with deterministic process exits on the two
required Linux hosts.

The visit does not claim to reproduce power loss, filesystem replay, torn
sectors, controller-cache loss, delayed input/output errors, Btrfs behavior, or
OpenZFS behavior. Those claims require a frozen block image or a controlled
power-cut system with declared cache semantics.
