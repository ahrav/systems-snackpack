# Topic 48 raw receipts

Each final run uses a stable directory named `YYYY-MM-DD-SOURCEPREFIX`. The
[2026-08-27 receipt](2026-08-27-43ba224/) contains the sealed source identity,
runtime `xxl` resolution, both host receipt archives, a SHA-256 manifest, and a
short receipt index. Superseded pilots stay outside the final directory and are
named as superseded evidence.
