# `xxl` host result: 2026-08-27

This run compares an ordinary scalar gather with the same gather plus one
low-locality read-prefetch hint on the host resolved from the `xxl` Secure Shell
alias. No randomized candidate established an improvement on this exact host
and binary. The distance-8 and distance-16 hints took longer with intervals
above 1; the other randomized intervals included 1.

## Fixed-work design

Each fresh process allocated 256 mebibytes (MiB) of 64-byte records, or
4,194,304 records.
It performed one untimed warmup pass and two timed passes for 8,388,608 measured
accesses. A deterministic seed, `0x0000000002dc6c30`, fixed the record order.
The randomized campaign tested distances 4, 8, 16, 32, and 64 records. These
distances issue a hint 256, 512, 1,024, 2,048, or 4,096 bytes ahead.

`A` is demand-only and `B` is the explicit prefetch. Each complete primary
block used four fresh processes in ABBA or BAAB order. Four blocks covered each
random distance. Two A/A blocks routed demand-only work through both labels.
The sequential control used distance 16 with two primary and two A/A blocks.
The complete block is the unit of replication. The randomized campaign
therefore contains 22 block replications, 20 primary and 2 A/A, drawn from 88
measured processes; the sequential campaign contains 4 blocks drawn from 16,
for 104 measured processes on this host.

The paired estimate is the geometric mean of `B/A` elapsed-time ratios across
complete blocks. In primary rows, values above 1 mean the hint took longer. In
A/A rows, both labels are demand-only. Each interval is a descriptive two-sided
95% Student-t interval over complete-block log ratios. It covers variation among
blocks in this host, binary, workload, and run window. It is not a
processor-family or fleet interval.

## Linked code

The host-built binary SHA-256 was
`a38c402cb2059cdba82865794e1c7b791e6c1bf6f6afc72063e0be5068fff947`.
The retrieved binary matched the hash recorded on the host. The linked
`kernel_demand` symbol at `0x401ef0` contained no explicit prefetch. The linked
`kernel_prefetch` symbol at `0x401f30` contained
`prefetchnta (%rdi,%rcx,1)`. This proves emitted code for this binary. It does
not prove that the processor honored a hint, where a line arrived, or why
elapsed time changed.
