# Round 01: scan granularity and completion

The complete lesson was delivered before repository mutation. Initial ephemeral
runs on both required Linux hosts passed eleven unit tests and one doctest, with
matching query outputs and 40 smoke-measurement processes per host. Initial timings
are not the final measurement dataset. The committed source is rerun independently.

The experiment compares equal predicates and explicit wrapping sums, checks empty
and partial ranges, nulls, extreme range sizes, and concurrent exact-once claims.
The completion control demonstrates that no remaining unclaimed range does not mean
no outstanding work. Generated-code inspection tests whether row dispatch actually
remained indirect. The performance comparison does not claim to isolate a single
microarchitectural cause or reproduce a database implementation.
