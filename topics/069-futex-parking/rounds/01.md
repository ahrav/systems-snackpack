# Round 1: publish state before waking

Four policies share the same exclusion, payload and sequential-oracle contract.
The uncontended path remains in userspace. The parking path keeps state 2 when
acquiring through the slow path so a later release continues the wake-one chain.
FUTEX_WAKE does not grant ownership or guarantee useful progress.

Initial correctness and192 process measurements/host completed in scratch. Initial clock placement included worker readiness; final
source adds a separate readiness phase. Use only final measurements for selection.

The source supports Linux AArch64 and x86-64 with 64-bit pointers. It intentionally omits timeout,
cancellation, process sharing, poisoning, robust ownership and priority inheritance.
The atomic payload prevents a non-atomic payload data race if exclusion regresses.

See [controls](../EXPERIMENT.md) and [evidence](../measurements/README.md).

identifies Topic 069; its scoped entry is retained alongside this round.
