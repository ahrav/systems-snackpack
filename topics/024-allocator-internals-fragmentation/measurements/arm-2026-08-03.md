## Result

Both treatments retained 4,194,304 requested live bytes, 4,325,376 usable live
bytes, and 6,557,696 `uordblks` bytes. Median post-trim RSS was 7,738 KiB for
compact and 73,008 KiB for scattered. The paired scattered/compact estimate
was 9.4443 with a 95% t interval of [9.4309, 9.4578] across 12 block
contrasts. The paired difference was 65,269.8 KiB [65,255.6, 65,284.1].

Median post-trim anonymous RSS was 6,500 versus 71,772 KiB. Median arena size
was 6,561,792 versus 73,400,320 bytes. Before explicit trimming, median RSS was
73,014 KiB for compact and 73,012 KiB for scattered. `malloc_trim(0)` returned
one in every row.

The allocation-loop ratio was 1.0004 [0.9981, 1.0027]. Startup and procfs
snapshots were outside that clock. The compact/compact A/A RSS ratio was
1.00493 [1.00205, 1.00783], which detected a small label or period effect in
this run window.

The final ELF was a dynamically linked ELF64 executable that needed only
`libc.so.6`. The final AArch64 image contained `bl` calls through PLT entries
for `calloc`, `malloc`, `memset`, `free`, `mallinfo2`, `malloc_trim`, and
`malloc_usable_size`.

These observations apply only to this host, binary, glibc build, workload, CPU
affinity, and run window. The raw bundle is [retained here](raw/c7187b1/arm/).
