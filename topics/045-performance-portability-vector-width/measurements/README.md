# Topic 45 measurement contract

This directory retains only checked-source results from the protocol in
[`../rounds/01.md`](../rounds/01.md). Each host note must name its Secure Shell
(SSH) target, resolved hostname, central processing unit (CPU) model,
architecture, kernel, toolchains, flags, selected CPU, fixed input, run count,
point estimate, interval, counter scope, code generation, and source identity.

The cross-host note compares observations without treating one host as evidence
for an instruction-set family. Raw host bundles and source-binding records belong
under [`raw/`](raw/).

The 2026-08-24 checked-source result is documented in the
[`xxl` host note](2026-08-24-xxl.md), the [Arm host
note](2026-08-24-arm.md), and the [cross-host
comparison](2026-08-24-comparison.md). Its sealed inputs and reports are under
[`raw/2026-08-24-edc75b26/`](raw/2026-08-24-edc75b26/).
