# Topic 45 measurement contract

This directory retains only checked-source results from the protocol in
[`../rounds/01.md`](../rounds/01.md). Each host note must name its SSH target,
resolved hostname, CPU model, architecture, kernel, toolchains, flags, selected
CPU, fixed input, run count, point estimate, interval, counter scope, code
generation, and source identity.

The cross-host note compares observations without treating one host as evidence
for an instruction-set family. Raw host bundles and source-binding records belong
under [`raw/`](raw/).

No final Topic 45 host receipt has been retained yet.
