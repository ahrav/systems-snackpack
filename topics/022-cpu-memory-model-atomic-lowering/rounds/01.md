# Round 1: ordering edges and exact lowering

This round separates the Rust/C++20 event graph from LLVM lowering and runtime
cost. The experiment keeps four evidence classes distinct: source semantics,
LLVM intent, final generated code, and bounded host observations.

The decisive controls are native versus generic AArch64 code generation,
Release/Acquire store-buffering where no load reads the peer release, and
Relaxed versus SeqCst operation shapes with matching or differing final
instructions.
