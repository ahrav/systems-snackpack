# Round 1: capacity, stale observations, and sampled candidates

For total arrival rate `lambda`, assigned fraction `p_i`, and capacity `mu_i`,
utilization is `rho_i = lambda * p_i / mu_i`. All rates use the same work unit.
At eight standard requests per millisecond and capacities `[4,4,1,1]`, equal
shares give `[0.5,0.5,2,2]`. Capacity shares `[0.4,0.4,0.1,0.1]` give 0.8 each.
This fluid calculation detects overload. It does not estimate a tail percentile.

For constant rates over delay `D`, extra backlog is approximately
`max(0, lambda * p_i - mu_i) * D`. Sending all eight requests per millisecond
to capacity four for two milliseconds adds eight requests. This assumes service
continues. The executable burst control deliberately pauses completions.

A request's serial equal-work completion estimate is `(q_i + 1) * s_i`, where
`q_i` counts unfinished requests ahead and `s_i` is service time. In the running
example, `(3 + 1) * 0.25 = (0 + 1) * 1 = 1` millisecond. Unknown remaining work,
parallel execution, or a shared dependency can invalidate that estimate.

Envoy 1.39.0 distinguishes equal-weight sampled/full-scan selection from an
unequal-weight scheduling path. The latter uses `w_i / (a_i + 1)^beta`, where
`w_i` is configured weight, `a_i` is the implementation's effective request count,
and `beta` is nonnegative bias. With bias one, `4/(3+1)=1/(0+1)=1`.
This is not a claim that every weighted policy samples two normalized queues.
The source supports optional inclusion of pending counts; inspect the active
runtime setting rather than treating a policy name as its full contract.

Classical two-choice theorems have arrival, service, sampling, and observation
assumptions. Our finite enumeration establishes neither an asymptotic queue
bound nor a production percentile. More choices can worsen correlated decisions
against stale reports. Current local reservations do not reveal other clients'
work. A connection can carry many HTTP/2 streams.

A cold server may need a relative traffic ramp. Scaling every endpoint's weight
by the same factor cannot lower total admitted demand. A destination with one
eligible endpoint has no within-destination alternative. Health ejection shrinks
capacity; panic fallback may intentionally reuse unhealthy endpoints. Test the
configured behavior. Retries also consume capacity: eight original requests per
millisecond times 1.5 attempts per request makes twelve attempts, above ten.

## Evidence contract

The initial scratch example runs before repository mutation on both required
Linux hosts. After commit, a path-limited archive and the exact committed runner
are SHA-256 checked before extraction/execution. The runner records host,
architecture, kernel, CPU, CPU count, toolchain, build flags, and target features.
It runs the focused tests, doctest, example, and optimized library code generation.

No clock is read by the model. Wall time would mostly describe this model's
implementation and startup, not the routing quality it illustrates. There is no
performance comparison, process-sample interval, or instruction-set speed claim.
A real performance study needs matched arrivals, failures, warm-up, load signal
age, and order-balanced independent process runs. Measure admitted work,
rejections, goodput, and latency together.
