## Generated code and counters

- `topic20_walk_one`: one `ldr w1, [x9, x10]`; the loaded `w1` determines the
  next iteration's address.
- `topic20_walk_eight`: eight `ldr` instructions update eight lane-local
  cursor registers; the XOR reduction occurs after the loop.

This is observed code shape, not proof of simultaneous outstanding misses.
Generic PMU smoke counters were usable, but they used a 16 MiB, 1,048,576-load
workload and were not paired with the retained timing run. They support no
queue, cache-level, or DRAM mechanism claim.
