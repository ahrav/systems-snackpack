# Round 1: Independent miss chains

Date: 2026-07-30

## Question

How much steady random-load latency can one core overlap when software changes
one dependent cursor into eight independent cursors?

## Design

- Treatment application: one fresh process.
- Assignment: seed-recorded restricted randomization over four AB and four BA
  blocks.
- Analysis unit: one complete process pair.
- Subsamples: useful loads inside a process. They do not add degrees of freedom.
- A/B stopping: eight complete pairs.
- A/A diagnostic: four complete pairs through both labels.
- Estimand: one-chain steady nanoseconds divided by eight-chain steady
  nanoseconds.
- Interval: two-sided 95% Student-t interval over paired log ratios.
- Startup: graph construction, page faults, and warm traversal are reported
  outside steady timing.

The fixed workload uses one deterministic random cycle, 4,194,304 64-byte
nodes, and 33,554,432 useful loads per process. Eight lane starts are spaced
around the same cycle. Every lane advances once per round, so the cursors do not
merge.

## Interpretation

The experiment establishes a code-shape and elapsed-time contrast. It does not
measure a fill-buffer count, DRAM request count, controller bandwidth, or loaded
latency. Those claims require model-specific counters with matching request and
scope definitions.

Cache-line splits and memory disambiguation remain documented controls rather
than measured treatments. Adding either to this comparison would change the
request population and confound the independent-chain contrast.
