# Topic 46 measurement contract

Checked-source host notes name the Secure Shell (SSH) target, resolved hostname,
architecture, processor model, kernel, toolchain, build flags, selected
processors and topology, coherence-line size, process count, point estimate,
dispersion, interval, code generation, PMU availability, and source identity.

The cross-host note compares observations without treating one host as evidence
for an instruction-set family. Raw source archives, host bundles, resolution
records, and validation receipts belong under [`raw/`](raw/).
