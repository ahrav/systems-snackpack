# Raw Topic 46 evidence

Each dated source-bound directory retains the Git commit and archive digest,
the `xxl` resolution, compressed Arm and x86 host bundles, and validation
receipts. The host bundles contain every scheduled process attempt and the
disassembly of the exact measured binary. A source archive that would duplicate
historic raw evidence can remain omitted when its prefix, byte count, digest,
and embedded commit were verified and recorded by both hosts.
