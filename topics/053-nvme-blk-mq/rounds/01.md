# Round 01: queue depth and completion cost

This visit connects NVMe submission and completion queues to Linux `blk-mq`
software and hardware contexts. It models concurrency, throughput, bandwidth,
and batched CPU cost. The native experiment compares one-thread direct reads at
depth one and eight on the two required Linux hosts.

The visit does not claim that a Linux asynchronous operation maps one to one to
an NVMe command, that sysfs topology proves dynamic queue use, that guest NVMe
means local flash, or that a cross-host difference is caused by instruction set
or processor vendor.
