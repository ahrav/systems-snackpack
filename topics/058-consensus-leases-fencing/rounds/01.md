# Round 1: permission at the effect

## Failure and control

W1 checks a lease at modeled time 90 ms, before expiry at 100 ms. W1 pauses.
W2 installs generation 42 at time 120 and writes value 20. W1's generation-41
write arrives at time 130. The resource rejects it and retains 20.

These are injected ordering events, not real clock measurements. The tests also
accept an old write before installation, reject future and zero generations,
exercise three legal handoff interleavings, and show that a separated check and
unconditional effect accepts a stale write. Copying complete state preserves the
fence; resetting state admits an old grant again. Neither test exercises a disk.

## Decision boundaries

Failure detectors provide suspicion. Consensus orders decisions among replicas.
Leases expire grants. Fencing rejects superseded work at a resource. A learner
copies state without voting before promotion changes the quorum requirement.
One mechanism does not supply the others' contracts.

A lease checked at the caller leaves a pause window before an external effect.
A highest-seen token on writes rejects old tokens only after the resource sees a
new one. Explicit installation gives a named resource-side handoff boundary.
If a grant-installation response is lost, reconcile the installed generation;
repeating `install` returns false even if the same generation already succeeded.

## Illustrative costs, not measured latency

For `n` distinct voters, majority size is `q(n) = floor(n/2) + 1`.
For the invoice coordinator, `q(3) = 2`; adding a fourth voter makes `q(4) = 3`.
An unready learner leaves the voting count unchanged during catch-up.

For old set `O={A,B,C}`, new set `N={C,D,E}`, and acknowledgers `S={A,B,C}`,
intersection sizes are `|S intersect O|=3` and `|S intersect N|=1`.
Joint acceptance is `(3 >= 2) AND (1 >= 2)`, which is false.

For a stable three-voter leader with parallel local and follower persistence,
let `P` be preparation, `L` local persistence, `F` the fastest eligible follower's
round trip including persistence, `A` application, and `C` client response time.
Then `T = P + max(L,F) + A + C`. With times in milliseconds,
`T = 0.2 + max(2,4) + 0.3 + 0.5 = 5`. Queueing, retries, larger quorums, and a
sequential storage adapter change the path. This is an illustrative model.

## Scope and next experiment

The focused runner compiles the exact committed library, tests, doctest, example,
and assembly on both required Linux hosts. There is no timing comparison:
local branch and set costs would not measure distributed failover or storage.
For a real service, inject pauses around the final effect, verify recovered fence
state, and record installation, acceptance, and commit events by operation ID.
