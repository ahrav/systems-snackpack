# Round 1: Exhaustion, cutoff, and replay

Date: 2026-09-27.

The focused question is whether a test explores the failing schedule and labels
its coverage honestly. Eight unit tests cover both increment models, exact-bound
termination, shallow cutoff, strict replay, and incomplete replay classification.
One doctest and the runnable example also pass on both required Linux hosts.

The broken split model exhausts six schedules and finds four lost updates.
The atomic model exhausts two schedules without failure. A depth-three search
of the split model reaches no terminal states and reports six cutoffs.

See [measurements](../measurements/README.md) for source identity, exact commands,
host details, receipt retention, and inference boundaries. See the
[source ledger](../references.md) for primary references. This round makes no
performance claim and does not implement a production simulator or Loom model.
