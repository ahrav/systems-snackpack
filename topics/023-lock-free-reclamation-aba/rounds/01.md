# Round 1: separate lifetime from identity

## Decision rule

Select a reclamation protocol from the longest permitted reader pause and the
maximum retained-memory budget. Add a generation only when CAS equality must
encode intervening history. A tagged pointer still needs lifetime protection
before dereference.

## Controls

- The raw arm must accept the forced ABA history and reintroduce B.
- The tagged arm must reject the same stale snapshot at generation 3.
- Both timing arms use `AtomicU64` and two successful CAS operations per loop.
- Fixed node storage removes use-after-free from the witness.
- Fresh-process ABBA/BAAB blocks and raw/raw A/A blocks bound the timing claim.
- Final-binary inspection records the emitted CAS instructions.

## Evidence boundary

Correctness establishes the fixed history only. Timing covers the named source,
binary, host, pinned CPU, workload, and run window. It does not rank reclamation
schemes or generalize to an ISA or processor family.
