# Round 01: ownership, cancellation, and terminal completions

This visit models the completion obligations that gate memory reclamation and
driver-ledger retirement. The native probe tests four contracts on the required
Linux hosts:

- baseline ring creation;
- `SINGLE_ISSUER` rejection of another submitting task;
- `DEFER_TASKRUN` completion visibility after owner `GETEVENTS` entry;
- separate cancel and target terminal CQEs.

The probe is a correctness experiment. It does not compare throughput or
latency. It does not test storage, submission queue polling, input/output
polling, registered resources, multishot requests, production seccomp policy,
or Linux Security Module policy.
